# Mobile App Notes - Marvin Burwell
Date: October 21, 2026

## What I Learned
- React Native uses components like View, Text, and TouchableOpacity instead of HTML elements.
- Expo makes it possible to run and test the mobile app without Android Studio or Xcode.
- The mobile app connects to the backend API using fetch requests.
- JWT tokens are used to authenticate protected requests.
- Pressing W in the Expo terminal opens the app in a web browser.
- StyleSheet.create() is used to define styles in React Native.
